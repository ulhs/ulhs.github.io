Privacy & Data Security Notice

In compliance with the Philippines Data Privacy Act of 2012 (RA 10173), this ID Generator operates locally. The student ID card and QR code use a public student ID number and a random secure token instead of the sensitive Learner Reference Number (LRN). Read our Privacy Policy for details.
