Privacy Policy

Upper Labay High School

1. Overview

In compliance with the Data Privacy Act of 2012 (RA 10173), Upper Labay High School (ULHS) is committed to protecting the personal information of its students, parents, and personnel. This policy explains how we collect, process, and protect data for our Student Information System (SIS), which includes:

  • Attendance Alert System via Facebook Messenger
  • Parent Portal for accessing grades, attendance, and achievements
  • Personnel/Admin Portal for managing student data

2. Data Collection

We collect the following types of data:

A. Student Information

  • Full name, Learner Reference Number (LRN), student ID number
  • Section, grade level, and photo (if provided)
  • Academic grades and term information
  • Achievements and awards
  • Attendance logs (time of arrival and departure)
  • Student portal account email and role/profile information used for access control

B. Parent/Guardian Information

  • Name and Facebook Page Scoped ID (PSID) for attendance alerts
  • Hashed PIN for Parent Portal login (PIN is never stored in plaintext)
  • Short-lived signed Parent Portal session token used to authorize portal requests
  • Secure confirmation tokens and Messenger verification codes used only to validate the parent registration process

C. Personnel/Teacher Information

  • Name and role for access to admin portals
  • Authentication credentials for login

D. Security and Access Metadata

  • Parent login-attempt records used to limit repeated failed login attempts
  • Grade visibility status, internal restriction reason, restoration time, and authorized staff operator for parent/student relationships
  • Administrative audit information needed to protect and operate the system

3. Secure Messenger Registration

To protect student privacy and prevent unauthorized linking, parent registration through Facebook Messenger is governed by a secure confirmation process:

  • Parents must begin the process through the official ULHS Parent Registration page
  • Each registration uses a unique secure token and confirmation code
  • Raw or direct LRN messages, direct REG_ values, and direct LINK values are not accepted as valid proof of identity
  • Messenger webhooks are validated using the Facebook app secret signature before any event is processed

This prevents unauthorized linking of a student's record to a random Facebook account. Parent registration is only completed after the secure confirmation code is validated in Messenger. More than one authorized parent or guardian may maintain a separate Messenger link to the same student.

4. Purpose of Processing

Data is processed solely for the following legitimate educational purposes:

  • Notify parents/guardians about their child's school attendance in real-time
  • Provide parents/guardians access to their child's academic performance (grades, achievements)
  • Temporarily restrict grade visibility for a specific parent/student relationship when authorized school procedures require it
  • Enable school personnel to manage, encode, and store student information, grades, and attendance

We do not use this data for marketing, profiling, or third-party sharing without explicit consent.

5. Data Storage & Security

All data is stored securely in a cloud database with strict Row Level Security (RLS) policies. Our security measures include:

  • Access restricted to authorized school personnel only
  • Password hashing and PIN encryption (no plaintext storage)
  • Short-lived signed sessions for Parent Portal requests; browser storage is treated as client-controlled
  • Server-side throttling on parent login attempts to prevent brute-force attacks
  • Relationship checks before returning parent student data or generating student photo URLs
  • Role-based access controls and RLS policies for personnel and student records
  • Secure connections (HTTPS) for all data transfers
  • Webhook signature verification for Messenger events using the Facebook app secret
  • Regular security audits and updates

6. Data Deletion & User Rights

In compliance with the Data Privacy Act of 2012, users have the following rights:

  • Right to access their personal data
  • Right to correct inaccurate data
  • Right to data erasure
  • Right to restrict processing
  • Right to data portability

To request data deletion or exercise other rights:

Method 1 (Messenger Link Removal): Send the message UNLINK [LRN] to our Messenger bot to remove your Messenger link from the student record.

Method 2 (Formal Request): Contact the ULHS ICT Department or message our official Facebook Page with a formal request for data deletion, correction, or access.

7. Contact Us

For questions regarding your data privacy, or to exercise your rights under the DPA, please contact our Data Protection Officer at the Upper Labay High School ICT Department or visit our official Facebook Page.
